天禧AI 概念版 v0.4（Windows 64 位）
======================================

这是一个真能跑的概念版天禧：底座是开源的 DeepSeek Harness（DSH 0.2.1-rc.2），
天禧自己的能力做成 DSH 插件，外面是一个 Windows 桌面客户端。不需要另装 Node 或 DSH。


一、打开
--------
1. 双击 TianxiAI 文件夹里的 TianxiAI.exe。
   第一次打开后，桌面和开始菜单会自动出现“天禧AI 概念版”快捷方式。
2. Windows 如果提示“已保护你的电脑”，点“更多信息 → 仍要运行”（这个程序没有数字签名）。
3. 第一次会让你接一个大模型：选服务商，粘贴你自己的 API Key，点“开始用天禧”。
   天禧会先试着调用一次，能通才会保存。Key 用 Windows 自带的加密保存在本机。
   支持：DeepSeek、通义千问、Kimi、智谱 GLM、豆包、Magpie 本机路由、Ollama 本机模型，以及任何 OpenAI 兼容接口。
   模型需要支持工具调用（function calling）。

   用 Magpie：先打开 Magpie，服务商选“Magpie 本机路由”，API Key 不用填。
   天禧会自动问 Magpie 有哪些模型，在“模型”一栏下拉直接选（名字是“服务商/模型”的格式）。
   Ollama 同理，先用 ollama pull 拉一个支持工具调用的模型。

关掉窗口不会退出，天禧会留在右下角托盘里继续运行。要退出：托盘图标右键 → 退出天禧。
快捷键 Ctrl + Alt + 空格 随时叫出天禧。


二、这一版的样子（v0.3 改版）
------------------------------
整体是一个 IM：左边是你的智能体列表和“我的”空间，中间聊天，右边是任务过程侧栏。

1. 智能体有人设：每个智能体有名字、头像颜色、身份、说话风格（靠谱同事 / 温暖贴心 / 犀利有梗）和自我介绍。
   点聊天顶部的头像能改；“新建智能体”可以从模板（出差助理、资料研究员、财务小秘）开始。
   设置里填“它怎么称呼你”。
2. 每个智能体有自己的邮箱（xxx@agent.local）：天禧可以给出差助理发邮件派活，出差助理收到会自己醒来去做，
   做完再回信。智能体之间的邮件不用你确认；发往外部地址的仍要确认。
3. 任务过程收在侧边栏：聊天里只留一句话和一个“做了 N 步”的小标签，点开右侧能看到每一步、为什么做，
   以及“这次改了这些”，可以逐条撤回或全部撤回。
4. 每日简报是单独的一页，不进聊天：今天最要紧的一件事放最上面，下面是卡片
   （需要你定 / 已经替你做完 / 还在做 / 值得知道），卡片里有日程冲突图、文件缩略图、进度、对比条等。
   “需要你定”的卡片点按钮，天禧直接去做，结果写回卡片上。
5. 我的记忆：所有智能体共用一份记忆，用星图看（按偏好、习惯、人物、项目、事实、经验分组，点大小=用过的次数），
   点一条看来源、改、删；也可以切成列表。最上面是“天禧眼中的你”。
6. 反思：天禧每天夜里（你不在电脑前时）回看最近的对话和你撤回过的事，写一份反思：
   它对你的新理解、记忆里该合并/修改/忘掉的条目、以后要注意的经验。每一条都由你点“采纳”才生效，采纳了也能撤回。
   也可以在反思页手动点“现在反思”。
7. 操作记录（原“天禧手账”）：天禧做过的每件事、为什么做、能不能撤回。
8. 还保留：临时模式、“算了”撤回上一步、后台任务、屏幕顶部的“天禧之光”、Ctrl + Alt + 空格 叫出天禧。

四、现在的边界（概念版）
------------------------
· 日程、待办、邮件是天禧自己的本地数据，还没接 Outlook、企业邮箱或手机日历。
  邮箱也在本机：智能体之间的邮件真的会送达，发往外部地址的只放进发件箱，不会真的发出去。
· 文件整理、读写文件、运行命令、上网查资料是真的会做的（用的是 DSH 自带工具）。
· 手机签字确认暂时没做，所有确认都在电脑上。
· 这一版的界面和流程只在我这边用模拟模型测过，真实模型的表现要你那边跑了才知道（可以用“评测”）。
· v0.2 的记忆、日程、手账数据会保留；之前的聊天记录归到“天禧”这个智能体下。


五、数据放在哪
--------------
全部在这台电脑上：%APPDATA%\TianxiAI-Concept
  data\      记忆、反思、操作记录、日程、简报、智能体和邮箱（JSON 文件）
  dsh\       DSH 的会话记录
  logs\      运行日志（runtime.log），出问题时把它发给我
  config.json 模型设置（API Key 已加密）
托盘右键 → “打开数据文件夹”可以直接打开。
要彻底重置：退出天禧后删掉这个文件夹。


六、源码
--------
“天禧源码.zip” 里是全部源码：
  tianxi\    DSH 插件（操作记录与撤回、记忆与反思、动作工具与邮箱、常驻感知与简报、多智能体客户端服务）和前端网页
  desktop\   Windows 桌面壳（Electron）
  build\     打包脚本


七、跑评测（量任务完成率和成功率）
----------------------------------
1. 打开天禧 → 设置 → “评测”（在“大模型”下面）。
2. 选“每个任务跑 3 遍”，点“开始评测”。30 个任务会在一个单独的沙盒里自动跑完，
   不碰你真实的下载、桌面、记忆和日程；需要确认的步骤会自动放行并计数。
   大约 1 到 3 小时，取决于模型速度，会消耗这个模型的 API 额度。可以随时点“停止”。
3. 跑完点“看报告”。结果在 %APPDATA%\TianxiAI-Concept\eval\<时间>_<模型>\：
   报告.md       完成率、成功率、3 遍全过的比例、平均调用次数和耗时、每个任务的结果
   results.json  每一遍的详细记录
   把这两个文件发给我，我按失败原因逐个修。
4. 想比较模型：在“大模型”里换一个（比如 DeepSeek → 通义 → Kimi），再跑一次。
   22、23 两题（查价格、查财报）标了“需人工复核”，网上的数字会变，脚本只判有没有给出处。

“评测任务包.zip” 是同样的 30 个任务和素材，每个任务一个文件夹，附“任务说明.md”，
用来手动在现在的天禧AI 或 Claude Code 上跑同样的任务做对照。


八、自动更新（v0.4 起）
----------------------
天禧会自己去 GitHub 仓库 Edifier-Ai/XT-harness 检查新版本，启动时查一次，之后每两小时查一次。
它只下载改过的文件，一般只有几十 KB。
· 你不在电脑前时，它自己重启换上新版本；你在用时，右下角会提示“现在重启 / 稍后”。
· 设置 → 更新：能看到当前版本，也能手动点“检查更新”。
· 新版本要是启动不了，天禧会自动退回上一个版本。
· 只有 Electron 或 DSH 底座升级时，才需要重新下载完整包，天禧会提示你。
